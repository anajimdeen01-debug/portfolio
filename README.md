Personal portfolio highlighting AI engineering, natural-language-to-SQL systems, full-stack applications, and workflow automation.

## 🚀 Live Demo

## 🛠️ Built With
- Pure HTML5, Semantic Elements & CSS3 (Custom properties, dark/light themes, responsive layout)

- Google Fonts (`Familjen Grotesk`, `Source Serif 4`)

## 📂 Local Development
Simply open `index.html` in any modern web browser or serve it with any static server:
```bash

npx serve .
```
